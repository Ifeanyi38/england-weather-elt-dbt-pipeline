# England Weather ELT Pipeline

ELT pipeline that loads hourly weather data for England from the Open-Meteo API into PostgreSQL, transforms it with dbt, orchestrate with airflow hosted on dcoekr and visualises it in Power BI.

## Stack
- Python (uv)
- PostgreSQL (Docker)
- dbt
- Airflow (Docker)
- Power BI
